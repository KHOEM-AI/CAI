2. ការរាប់ស្ទួនរវាងរូបច្រើន (Bulk / 360°) មិនអាចដោះស្រាយដោយស្វ័យប្រវត្តិ ត្រូវកែលេខដោយដៃ ។
3. កម្រិតព្រិល/ងងឹតជាការប៉ាន់ស្មាន មិនទាន់កែតម្រូវជាមួយរូបពិត ។
4. ម៉ូដែលទាញពី CDN លើកដំបូង ត្រូវអ៊ីនធឺណិត ។
