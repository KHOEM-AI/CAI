# កូដត្រឹមត្រូវសម្រាប់ CAI Pro Vision (កំណែទី ២ — ផ្អែកលើកូដពិតដែលឃើញរួច)

⚠️ សំខាន់៖ នេះជាកំណែថ្មីដែលផ្គូផ្គងទៅនឹងកូដពិតក្នុង `cai-auth.ts` និង `cai-scans.ts`
ដែលបានឃើញរួច — មិនមែនកំណែសន្មតដូចមុនទេ។ សូមប្រើកំណែនេះជំនួសកំណែចាស់ទាំងស្រុង។

## ១. File: `lib/db/src/schema/cai.ts` (បង្កើត file ថ្មី — កុំកែ index.ts ចាស់)

```typescript
import { pgTable, text, integer, boolean, doublePrecision, timestamp, jsonb } from "drizzle-orm/pg-core";

export const caiUsersTable = pgTable("cai_users", {
  id: text("id").primaryKey(),
  name: text("name").notNull(),
  email: text("email").notNull().unique(),
  passwordHash: text("password_hash").notNull(),
  role: text("role").notNull().default("staff"), // "staff" | "admin"
  createdAt: timestamp("created_at").defaultNow().notNull(),
});

export const caiScansTable = pgTable("cai_scans", {
  id: text("id").primaryKey(),
  operatorId: text("operator_id").notNull(),
  batchId: text("batch_id").notNull(),
  category: text("category").notNull(),
  totalCount: integer("total_count").notNull(),
  detectedTypes: jsonb("detected_types"),
  hashSignature: text("hash_signature"),
  aiAssisted: boolean("ai_assisted").default(false),
  latitude: doublePrecision("latitude"),
  longitude: doublePrecision("longitude"),
  createdAt: timestamp("created_at").defaultNow().notNull(),
});
```

## ៣. File: `lib/api-zod/src/schema/cai.ts` (បង្កើត file ថ្មី)

```typescript
import { z } from "zod";

// ---------- Auth ----------
export const LoginBody = z.object({
  email: z.string().email(),
  password: z.string().min(1),
});

const CaiPrincipal = z.object({
  id: z.string(),
  name: z.string(),
  email: z.string(),
  role: z.enum(["staff", "admin"]),
});

export const LoginResponse = z.object({
  token: z.string(),
  user: CaiPrincipal,
});

export const GetCurrentUserResponse = CaiPrincipal;

// ---------- Scans ----------
const ScanItemShape = {
  id: z.string(),
  operator: z.string(),
  category: z.string(),
  batchId: z.string(),
  totalCount: z.number(),
  detectedTypes: z.unknown().nullable(),
  hashSignature: z.string().nullable(),
  aiAssisted: z.boolean().nullable(),
  latitude: z.number().nullable(),
  longitude: z.number().nullable(),
  createdAt: z.string(),
};

export const ListScansResponseItem = z.object(ScanItemShape);

export const CreateScanBody = z.object({
  batchId: z.string(),
  category: z.string(),
  totalCount: z.number(),
  detectedTypes: z.unknown().optional(),
  hashSignature: z.string().optional(),
  aiAssisted: z.boolean().optional(),
  latitude: z.number().optional(),
  longitude: z.number().optional(),
});

export const CreateScanResponse = z.object(ScanItemShape);

export const ListScansQueryParams = z.object({
  limit: z.coerce.number().default(50),
});

export const ListScansResponse = z.array(ListScansResponseItem);

// ---------- Dashboard ----------
export const GetDashboardSummaryResponse = z.object({
  totalScans: z.number(),
  totalItems: z.number(),
  todayScans: z.number(),
  categoryCounts: z.record(z.string(), z.number()),
  recentScans: z.array(ListScansResponseItem),
});
```

## សរុប — ជំហានធ្វើក្នុង Replit (តាមលំដាប់ត្រឹមត្រូវ)

**ដំណាក់កាលទី ១ — Database Schema**
1. បង្កើត file ថ្មី `lib/db/src/schema/cai.ts` → paste កូដទី ១
2. បើក `lib/db/src/schema/index.ts` (file មានស្រាប់) → **លុបមាតិកាចាស់ទាំងអស់** → paste កូដទី ២ ជំនួស
3. Save

**ដំណាក់កាលទី ២ — API Contract (Zod types)**
4. បង្កើត file ថ្មី `lib/api-zod/src/schema/cai.ts` → paste កូដទី ៣
5. បើក `lib/api-zod/src/index.ts` (file មានស្រាប់) → **លុបមាតិកាចាស់ទាំងអស់** → paste កូដទី ៤ ជំនួស
6. Save

**ដំណាក់កាលទី ៣ — សាកល្បង (កុំប៉ះ App.tsx ឬ routes ទាល់តែសោះ)**
ចូល Shell រត់តាមលំដាប់នេះ (ត្រូវការ DATABASE_URL និង SESSION_SECRET ក្នុង Secrets/`.env` ជាមុន បើមិនទាន់មាន):
```
cd ~/CAI-new
pnpm run typecheck
```
បើ `lib/db` និង `lib/api-zod` ចេញមក **គ្មាន error** → បន្តទៅ:
```
pnpm run build
```

**កុំធ្វើអី្វបន្ថែមទៀត បើមិនទាន់ឃើញលទ្ធផលនៃជំហាននេះ** — ត្រូវផ្ញើ output មកឲ្យអ្នកវិភាគមើលសិន មុននឹងទៅដល់ `api-client-react` និង `App.tsx`។

## ចំណាំសំខាន់សម្រាប់អ្នកវិភាគ (AI ដែលកំពុងជួយត្រួតពិនិត្យ)

- `caiScansTable.id` និង `caiUsersTable.id` ប្រើ `text` (មិនមែន `uuid`) ព្រោះកូដ `cai-scans.ts` ប្រើ `id: \`scan_${crypto.randomUUID()}\`` ជា string prefix — មិនមែន UUID សុទ្ធ
- `LoginResponse` មាន field `token` (មិនមែន `accessToken`/`refreshToken`) — ត្រូវនឹង `signToken()` ក្នុង `cai-auth.ts` (lib)
- `ListScansQueryParams.limit` មាន `default(50)` ព្រោះកូដ route ហៅ `.limit(parsed.data.limit)` ដោយផ្ទាល់ដោយគ្មានពិនិត្យ undefined
- `api-zod/src/index.ts` ចាស់ reference file `./generated/types` ដែលមិនមាន — នេះជា error ដាច់ដោយឡែកមួយ ត្រូវកែផង
